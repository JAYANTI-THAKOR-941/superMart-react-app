# SuperMart React App

React storefront UI with reusable header, hero, product and footer components.

## Project structure

- `src/components/Header.jsx`
- `src/components/Hero.jsx`
- `src/components/Products.jsx`
- `src/components/Footer.jsx`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/superMart-react-app.git
cd superMart-react-app
```

Run `npm install` and `npm run dev`.
